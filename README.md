# RiftWii Retro USB-Only

Projeto em implementação sobre a fonte USB-only recuperada da versão 2610-699.

Não há ainda um pacote Retro Complete validado. O build e o retorno dos emuladores precisam de verificação. IOS246 não deve ser alterado. Nenhuma ROM ou BIOS proprietária será distribuída.
